#YouTube-Revenue-Optimization-Using-Engagement-Metrics

The dataset analyzed in this project was taken from a Kaggle post linked here.
https://www.kaggle.com/datasets/rv31121999/youtube-channel-real-performance-analytics?resource=download

This project analyzes a real YouTube performance dataset (364 videos, 70+ features) to uncover how viewer engagement metrics influence monetization.

The goal: help content creators and media strategists optimize upload timing, video engagement, and audience retention to maximize revenue.

Methods & Tools...

Data Cleaning & Transformation: Python (pandas, numpy)

Statistical Testing: Hypothesis tests (t-test with scipy)

Visualization: matplotlib, seaborn

Dashboarding: prepared for Tableau / Power BI for dashboarding.

Key Findings...

 - Premium views generate ~43.2% more revenue per view than regular views.

 - Medium-length videos (3-10m) often balance engagement & profitability best.

 - Medium-size CTR (5-10%) correlates with higher revenue per view.

 - Thursday, Tuesday, and Friday generate the most revenue per view on average.
